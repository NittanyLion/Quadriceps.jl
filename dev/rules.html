Written by build/build_data.jl. q: the argument of ghpos(d, q) and lepos(d, q); p = 2q - 1: degree of exactness; n: number of nodes; ρ = n^(1/d) / q: the node count relative to the q^d Gauss product grid (1.00 is that grid, smaller is better); Möller: Möller's lower bound on n (bold n: bound attained, proven minimal); rel. err.: largest relative monomial error of the stored Float64 rule; origin: own, or the published rule it is, or descends from (see Credits).
